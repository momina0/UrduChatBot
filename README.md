
🗣️ Urdu Chatbot — An NLP Model for Conversational Urdu

This project presents an Urdu Chatbot built using deep learning and natural language processing (NLP) techniques.
The chatbot is trained on Urdu conversational data and can generate contextually meaningful replies to user inputs in Urdu.

✨ Features

💬 Generates human-like Urdu responses using a Seq2Seq Transformer model

🧠 Trained and evaluated with BLEU, chrF, ROUGE-L, Perplexity, and Accuracy metrics

🧾 Interactive interface powered by Gradio

🌐 Deployed permanently on Hugging Face Spaces

⚙️ Built using PyTorch, SacreBLEU, and Hugging Face Transformers
